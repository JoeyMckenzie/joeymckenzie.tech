# Nocturne expands into the admin by bounded surfaces

Nocturne is the site's shared visual language, but it will expand from the public site into the authenticated admin deliberately rather than through a global rewrite of shadcn/Base UI tokens. The post create/edit surface is the first bounded adoption: it reuses the namespaced Nocturne palette and typography while preserving the existing admin shell, component semantics, accessibility, and behavior. The shell and post index remain separate follow-up surfaces so each interaction model can be designed and verified without turning an editor styling pass into an all-at-once admin redesign.

The post editor is a **Nocturne authoring desk**: an open editorial canvas with Story, Content, and Publishing sections separated by hairlines; a prominent Fraunces title field; a wide source/preview workspace; and a restrained sticky authoring statusline. CodeMirror receives only structural Nocturne theming while retaining its syntax highlighting and mechanics. Existing shadcn/Base UI primitives remain the control foundation, semantic destructive colors remain errors, and the corrected Select portal/positioning anatomy is not traded for visual consistency. Nocturne continues to follow the operator's selected light or dark appearance and keeps its one-motion rule: the first-light page-header sweep, then silence.

This staged boundary is intentional. A global semantic-token remap would make unrelated authenticated screens change implicitly, while retaining default scaffold styling inside the editor would disconnect authoring from the published artifact. Bounded adoption makes the design reusable without hiding regressions in navigation, tables, overlays, forms, or responsive behavior; later shell and post-index passes can build on the editor as the reference surface.
